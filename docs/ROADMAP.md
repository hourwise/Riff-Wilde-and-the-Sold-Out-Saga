# Roadmap

## Phase 1 — Vertical Slice (Current)

**Goal:** Answer "Is it fun to move, swing the lute, shout enemies, and chain combos?"

- [x] Player movement, camera, dodge
- [x] Strike (Lute-Bludgeon) combat
- [x] Sing (Vocal Wave) combat with Resonance scaling
- [x] Verse-Chorus combo system (Intro, Bridge, Crescendo)
- [x] Enemy AI: Tone Deaf (swarm) + Ironclad Warden (armored)
- [x] Tavern hub with mission loop
- [x] Score/XP system with Encore results
- [x] Local save/load
- [ ] Firebase cloud sync (optional, offline-first)
- [ ] Audio spectrum analyzer (reactive VFX)
- [ ] Windows desktop export

## Phase 2 — Demo Polish (Future)

- Replace placeholder assets with themed low-poly art
- Add background music and SFX
- Add 1-2 more enemy types
- Add 1 mini-boss encounter
- Basic dialogue/NPC interaction in tavern
- Itch.io private test build

## Phase 3 — Public Demo (Future)

- 3-mission campaign arc
- Skill tree / upgrade system
- Steam page + wishlist setup
- Public Itch.io demo

## Phase 4 — Full Game (Future)

- Full campaign with multiple biomes
- Boss encounters
- Voice acting and full soundtrack
- Steam + Itch.io commercial release
